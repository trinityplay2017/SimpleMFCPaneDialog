# SimpleMFCPaneDialog

Minimal MFC dialog-based Windows application.

## Build
Open `SimpleMFCPaneDialog.sln` in Visual Studio (with MFC support installed) and build.

## Files
- `SimpleMFCPaneDialog.cpp` / `.h` – application class
- `SimpleMFCPaneDialogDlg.cpp` / `.h` – main dialog
- `resource.h` + `SimpleMFCPaneDialog.rc` – resources
- Project files for VS
